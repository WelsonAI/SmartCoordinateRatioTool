# Smart Coordinate & Ratio Tool

An interactive manipulative for SK and SJKC pupils in Years 4–6, aligned to the coordinate, ratio, proportion and scale topics in the Malaysian mathematics textbooks.

## Learning progression

- **Year 4:** read and plot first-quadrant coordinates, build object ratios, and explore unit rates.
- **Year 5:** compare horizontal and vertical distance, trace coordinate routes, distinguish part-to-part from part-to-whole ratios, and find unknown proportional quantities.
- **Year 6:** use scaled coordinate grids, simplify equivalent ratios, and convert map distance to actual distance.

## Interaction principles

- Points and map pins follow the mouse or finger directly and snap to the nearest grid position.
- Every slider changes the diagram and its explanation together.
- Malay, Chinese and English interfaces are included.
- Teacher settings, reset, random examples and optional click sounds follow the same product language as the other Smart tools.
- Responsive layouts support classroom screens, tablets and phones.

## Run locally

Open `index.html` directly, or serve the folder with any static web server.

## Scope boundary

Length, mass, capacity and unit-conversion activities belong to Smart Measurement Lab. Distance in this tool means coordinate-grid displacement or map-scale distance, avoiding duplicate measurement activities.
